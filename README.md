# Melora Releases

Public distribution for [Melora](https://melora.zausau.com): signed DMG/ZIP assets and the Sparkle `appcast.xml` used for in-app updates.

- Download the latest version from the [Releases](https://github.com/monoedge-labs/melora-releases/releases/latest) page. Requires macOS 14.0 or later.
- Report bugs or installation problems in [Issues](https://github.com/monoedge-labs/melora-releases/issues).
- Ask questions and share feedback in [Discussions](https://github.com/monoedge-labs/melora-releases/discussions).
